# new-site

## Galenite Design System

Base reference: AI OFFICE

### Core principles

- monochrome interface
- minimal text
- large whitespace
- smooth motion
- soft borders
- no random gradients
- no different fonts between pages
- one ecosystem feeling

### Typography

Primary font:

```txt
Inter
```

### Colors

```css
--bg: #f5f5f3;
--surface: rgba(255,255,255,0.72);
--text: #101010;
--muted: #666666;
--border: rgba(0,0,0,0.08);
```

### Radius

```css
32px
```

### Forbidden

- bootstrap style blocks
- colorful UI
- heavy shadows
- neon gradients
- random paddings
- different animation styles
- different navbar styles

### Structure

Every page should feel like one product.

Shared:

- navbar
- spacing system
- typography
- transitions
- buttons
- cards
- section layout
