# Galenite Auth sticker

Для стикера авторизации можно положить в эту папку:

- `auth.json` — Lottie-анимация (приоритетный формат);
- `auth.svg` — статический SVG.

Если присутствуют оба файла, используется `auth.json`. Пока ни одного из них нет, страница использует существующий `auth.gif` как legacy fallback.
